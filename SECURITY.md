# Security Policy

Please report suspected vulnerabilities privately through GitHub Security Advisories:

https://github.com/mynameistito/gmessages-cf/security/advisories/new

Do not include credentials, cookies, session keys, access tokens, message content, or other sensitive data in a report. Provide the smallest useful reproduction and redact secrets from logs and screenshots.

If private reporting is unavailable, open a public issue without sensitive details and request a private contact channel.
